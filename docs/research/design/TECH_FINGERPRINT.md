## What the table shows

1. **No site is smooth because of a smoothing library, as far as this probe can tell.** All 14 jump instantly on a wheel tick (page position changes in 2 samples, within 26 to 108 ms), including spacefs, which ships Lenis code. A Lenis-style layer would eventually approach the target over several hundred milliseconds. Caveats: one desktop Chrome wheel event in a headless browser; a library might only activate with other input or breakpoints; **real-device feel was not observed**.
2. **Nobody uses native CSS scroll-driven animation yet** (`animation-timeline` in CSS: 0 of 14). Eight of the 14 ship Motion code (adaline, handhold, modeinspect, pexo, spacefs, legora, wama, workos atlas) that checks for a native `ScrollTimeline` before falling back to JavaScript, so some scroll-linked effects there may run natively in Chrome. Not verified per effect.
3. **GSAP is confirmed on two sites only (monday, clay), both Webflow builds and both among the heaviest** (monday 3.8 MB of JS and Lighthouse 29; clay 3.1 MB and 41). three.js is confirmed on adaline, spacefs and handhold; Lottie on iru and crealo.
4. **Weight is what separates the sites, not the stack.** Across the 14, mobile Lighthouse falls as first-load JavaScript rises (Spearman rank correlation **-0.75**, n = 14) and, less strongly, as total first-load bytes rise (**-0.54**). The lightest, getenergy (114 KB JS, 0.4 MB total), scores 98 with no animation library detected; the next two are modeinspect (81, Motion only, 528 KB) and adaline (78, Motion + three.js, 690 KB). All the other sites score 76 or lower. The two sites with GSAP score lowest. Nine of the 14 exceed 1 MB of first-load JS; iru's 2.2 MB is, per its card, about 95% third-party tags. Correlation, not proof: n is small and sites differ in more than libraries.
5. **Answer to "which of the sites we admire feel smooth because of a library and which with native techniques?"** From the evidence: none feel smooth because of a smoothing library. The motion that makes them feel polished is entrance and hover motion done with CSS keyframes, Web Animations or Motion, plus a few bespoke pieces (legora's pinned scrubbed video, adaline's WebGL aurora, iru's hand-authored Lottie, clay's GSAP-driven navigation). The calmest pages (iru: 0 of about 920 elements changed under scroll; getenergy; modeinspect) are native-scrolling and mostly still. Perceived smoothness on a real device was not tested.
