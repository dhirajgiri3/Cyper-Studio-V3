# HELIX Home Lab (Brief 01 v2.1): PROPOSALS ONLY, nothing locked

Nothing in here is production. Nothing locks until the founder replies `LOCK HOME v1`.

| Path | What |
|---|---|
| `compare.html` | The four heroes side by side: ID overlays, 1440/390, palette P1/P2, TYPE-1/2/3, reduced motion, interact on/off |
| `heroes/hero-*.html` | HERO-A to HERO-D, each a standalone HTML file (inline CSS, no external requests). Generated by `heroes/_build/` (`node build.mjs`) |
| `heroes/results/` | Measurement output (`measure.json`, Lighthouse in `motion-bench/results/lh-hero-*.json`) |
| `brand/` | Wordmark vector proposals, compact-mark concepts, brand audit page (`index.html`), measurement JSON |
| `motion-bench/` | The five motion-stack candidates (S0 to S4), atmosphere variants, measurement scripts, results, `feel-test.html` |
| `tools/` | Capture and measurement tooling (own `package.json`; `node_modules` is gitignored): `probe.mjs` (reference-site capture), wordmark scripts, `shot.mjs` |
| `research-captures/` | Run logs for the reference-site captures |

Run it locally (two static servers; ports are only used for lab measurement):
```bash
cd design-system/home-lab/motion-bench && node build.mjs && node build-atmos.mjs
node serve.mjs dist 4173 &            # bench candidates
node serve.mjs ../.. 4174 &           # heroes, compare page, brand page (serves design-system/)
# open http://127.0.0.1:4174/home-lab/compare.html
```
Re-measure: `bash motion-bench/run-measurements.sh` (quiet machine, about 1 hour). Raw screenshots stay gitignored; committed images are under 100 KB.
